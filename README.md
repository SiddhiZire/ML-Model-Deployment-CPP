# Machine Learning Model Deployment using C++

## Image Classification System

A machine learning model deployment project that uses C++ and ONNX Runtime to perform image classification.

## Objective

To deploy a trained machine learning model in a C++ application and perform image classification with prediction confidence and inference time.

## Technologies

- C++
- Python
- Machine Learning
- ONNX
- ONNX Runtime
- OpenCV
- CMake
- Git & GitHub

## Project Pipeline

Python Model
→ ONNX
→ C++ Application
→ OpenCV
→ ONNX Runtime
→ Prediction
